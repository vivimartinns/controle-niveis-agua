
# 💧 Controle de Níveis de Água

Projeto desenvolvido para a Agenda 11 de Desenvolvimento
de Sistemas.

## 📌 Objetivo
Simular o monitoramento de um reservatório de água,
exibindo cinco níveis com mensagens coloridas.

## 🛠️ Tecnologias
- Python
- Biblioteca Colorama
- Visual Studio Code

## 🚀 Como executar
1. Instale o Python.
2. Instale a biblioteca: python -m pip install colorama
3. Execute: python vivian_Ag11_DSI.py

## 📊 Funcionalidades
- Lista com cinco situações do reservatório.
- Função para definir a cor de cada nível.
- Exibição das mensagens coloridas no terminal.
- Restauração automática do estilo padrão.
